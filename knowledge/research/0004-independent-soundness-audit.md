## Verified source observations and testable findings

`Model::new` bounds and validates dense states and edges, rejects an empty initial set and duplicate/unknown set members, preserves duplicate transitions and action labels, and accepts an empty bad set. Fields are private. A missing failure transition or untrusted observation cannot be detected from the graph alone. Quotient search marks initial and bad blocks existentially and scans concrete transitions, while concrete feasibility retains all matching successors; replay checks labels against concrete edges. Limits and cancellation propagate as inconclusive, including during replay. Partially applied split on cancellation is local to the aborted run, not a model mutation.

At the audited head, xtask's reference algorithm and witness checker read the constructed Model's getters. A constructor that accidentally drops an input edge, initial or bad state could affect both sides and escape comparison. The accompanying change preserves raw fixtures for backward reachability and independent witness validation and checks getter round trips; it retains the separate closure oracle and does not reuse quotient, concretization or replay. It still shares the Rust compiler, input generation, `Transition::new` and modeled graph semantics; independence here is from `Model::new`, not every constructor. Returned witnesses are independently checked against raw labeled edges.

A direct private-partition reproducer exposed a precision distinction: `n=6`, initial `{0}`, bad `{5}`, partition `[0,1,1,2,2,3]`, edges `(0,10,1),(2,20,3),(1,20,4),(3,30,5)` in order. The selected blocks/actions are `[0,1,2,3]` / `[10,20,30]`. The final blocked frontier `{4}` is split from state 3, yet a refined block/action word maps back to the original under coarsening via the incompatible earlier prefix through state 2. The numeric IDs coincide, but refined block 2 is a smaller set than old block 2. The regression exercises this arbitrary partition, **not a demonstrated partition reached by the public coarse-start loop**. Thus a strict split removes the encountered frontier mismatch, but not necessarily the whole abstract word. The formal-model explanation now says so; whether to require stronger per-word elimination is a review question.

The old xtask witness checker imposed a `state_count` length cap while public replay accepts cyclic witnesses up to `MAX_STATES`. That was harmless for the current verifier's simple abstract BFS paths but overconstrained the independent checker if reused more generally. The audit change aligns its bound with replay's documented structural bound; it remains independently implemented.

`Report` is a public, forgeable in-memory data structure with a constant scope string, not an authenticated model-bound receipt. It has no model or policy identity. A future adapter must bind exact inputs, revisions and provenance and must not treat a supplied or substituted Report as an authority token. This is a future integration requirement, not evidence that `verify()` returned a wrong graph result. Execution authorization remains false.

## Mathematical argument, not implementation proof

For any partition, mapping each concrete state to its block projects every initial, every labeled edge and every bad state into the existential quotient. Mapping a concrete bad path therefore gives an abstract bad walk. BFS with a visited set determines block reachability even for loops and parallel edges; a completed abstract search with no reachable bad block implies no concrete bad path in the supplied model.

At a blocked step the feasible frontier is nonempty and proper: the quotient edge exists from some block member, but no member of the frontier can take it. At a bad endpoint disjoint from the frontier, the block contains a bad state outside the frontier. A split preserves every state and rebuilds all edge projections, adds a nonempty block, and can succeed at most `n-1` times. The singleton partition is exact. Witness backtracking follows recorded actual predecessors; independent replay is a separate guard. Each conclusion depends on correct implementation and successful bounded completion. Any limit, cancellation or internal invariant failure returns inconclusive, not verified.

## Tested properties, hypotheses and falsifiers

The accompanying tests directly exercise all contiguous nonempty assignments of four states to blocks, isolated cross-block concrete edge reachability for two action labels, same-block zero-step reachability, initial/bad subset overlap without edges, a blocked-frontier split, and the surviving-word example. Because the BFS immediately reaches Bad in the same-block case, its test cannot observe a self-block edge or label. Additional integration cases exercise renaming, edge reordering, duplicate and parallel labeled edges, multiple initial/bad states, nondeterminism, bounds, refinements and cancellation cutoffs. See the evidence record for actual commands and results; test families are finite and are not a proof of every implementation state.

Hypothesis: all reachable partitions obey the strict progress argument; the audit found no counterexample, but no mechanized proof or exhaustive enumeration of all 128-state labeled graphs exists. Rejected alternatives: weakening safety to avoid exhaustion, reusing the implementation's replay in the oracle, replacing the checker with an SMT/service stack, or presenting a shared-constructor oracle as input-independent. A dropped initial/bad/edge projection, changed label, feasible successor loss, invalid accepted witness, non-proper split, false verified result, or non-inconclusive exhausted run falsifies the corresponding conclusion and must be preserved as a synthetic regression.

Outstanding: graph completeness, input provenance, policy compilation, receipt identity, scheduling/failure semantics, hard RAM/deadline enforcement and trusted observations remain outside this library. Direct mutation checks exercise oracle sensitivity, not comprehensive mutation testing of production code. Test outputs and CI revisions belong in `knowledge/evidence/`, not this argument.
